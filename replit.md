# Photo Gallery

This is a React and TypeScript photo gallery built with Vite and Tailwind CSS.

## Run on Replit

- The **Start application** workflow runs `npm run dev`.
- Vite listens on `0.0.0.0:5000` and permits Replit's proxied preview host.
- Run `npm run build` for a production build.
- Run `npm run lint` for the TypeScript validation check.

The gallery currently loads its sample photos from Unsplash and does not require secrets or external services.
